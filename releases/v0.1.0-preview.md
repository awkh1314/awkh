# AWKH Public Experience 0.1.0-preview

<small>Release date: 2026-11-22 · Status: Preview · Distribution: Documentation and hosted experience</small>

## Connect to the official public MCP

`https://mcp.awkh.art/connect/mcp`

The endpoint connects to the AWKH-operated shared experience service. Use OAuth and complete authorization on the AWKH domain.

## Included

- ChatGPT/custom MCP connection instructions.
- OAuth onboarding guidance.
- Windows/Linux Agent onboarding guidance.
- Device registration and Owner approval explanations.
- Feature overview and security notes.
- Clear distinction between the official shared platform and customer private deployments.

## Not included

- AWKH proprietary server source.
- Customer private-deployment source or offline deployment package.
- Binary Agent installers or release assets.

## Important notes

- This is a preview release for testing and evaluation, not a production GA declaration.
- A successful OAuth connection does not mean a device has been enrolled.
- An installer finishing does not mean the Agent has completed registration, approval, or heartbeat.
- Only connect devices you own or are explicitly authorized to administer.
- Available capabilities, permissions, and quotas are determined by the hosted service at the time of use.
